#  FeliksOS Mobile v1.5

**A terminal operating system for UserLAnd (Debian).**

Made for **fun**, experiments, and learning.  
It will get **better** — I promise. 

---

##  What is this?

FeliksOS Mobile is a **toy OS** in your terminal.  
It doesn't replace Linux. It **complements** it.  
It's a **sandbox** for those who want to feel like a Kernel.
